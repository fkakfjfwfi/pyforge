书不用多，按阶段读对 5 本就够

这里的书目来自图灵社区、豆瓣与作者公开页面，覆盖入门、进阶、工程、底层与爬虫五个方向。每本都标注了「适合谁、怎么读、对应本站哪几章」，避免买回来吃灰。

GITHUB · OPEN SOURCE

GitHub 上的优质开源教材

仓库的优势是免费、可运行、更新快。适合作为书的补充：一边读概念，一边把示例代码跑起来。

怎么安排阅读顺序
IF 你的基础还不稳

《Python编程：从入门到实践》快速过一遍 → 《Python编程轻松进阶》补断层 → 再回本站第 1–6 章对照练习。

IF 你想尽快提升爬虫能力

《流畅的Python》第 1/5/6/14 章 → 《Python 3网络爬虫开发实战》第 2–7 章 → 本站第 7–9 章（生成器/并发/异步）。

IF 你已经开始写项目

《Python工匠》→ 《Architecture Patterns with Python》→ 《Python Testing with pytest》，同时把项目按第 10 章的结构重构。

IF 你想弄懂「为什么」

《CPython设计与实现》→ 《Python源码剖析》（选读）→ 对照 CPython 源码看 dict、引用计数与 GIL 的实现。
